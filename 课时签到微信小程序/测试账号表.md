## 五、账号切换与解绑

### 5.1 如何切换账号（同一台手机）

| 方式 | 操作 |
|---|---|
| **方式一（推荐）** | 「我的」页 →「**退出登录**」（清除本机 token 与身份）→ 回首页点「去绑定」→ 填写新身份/工号学号/姓名 |
| **方式二** | 「我的」页 →「**重新绑定**」→ 自动带出当前信息，直接改成目标账号即可 |

> 说明：「退出登录」只清**本机**登录态，**不会**删除服务端的绑定关系。

### 5.2 支持自由切换吗？

| 场景 | 行为 |
|---|---|
| **测试环境（开发模式）** | ✅ **自由切换**：退出后可绑定任意白名单账号，可反复来回切 |
| **正式上线后（生产模式）** | ⚠️ 微信是真实身份，**一个微信号只能绑一个工号**（防冒名）；换绑走下面的「自助解绑」或联系教务处 |

### 5.3 自助解绑 / 换绑（无需找教务处）

| 场景 | 入口 | 校验 |
|---|---|---|
| **本人想换绑其他账号** | 「我的」页 →「**解绑当前微信**」 | 已登录即可（最安全）|
| **换了新微信、登不进去** | 绑定失败提示"已被其他微信绑定"时 →「**自助解绑并重新绑定**」 | 工号/学号 + 姓名（白名单校验）+ 频率限制 + 审计留痕 |

**操作步骤**：

**A. 本人解绑（当前微信还能用）**
1. 「我的」页 → 点「**解绑当前微信**」→ 弹窗确认
2. 解绑成功 → 自动清除本机登录态并回到绑定引导
3. 重新绑定目标账号即可

**B. 换微信自救（旧微信已不用了）**
1. 用**新微信**打开小程序 → 按引导填写原来那个工号/学号 + 姓名 → 点绑定
2. 提示"已被其他微信绑定" → 点出现的「**自助解绑并重新绑定**」
3. 弹窗核对工号 + 姓名（保证输入无误）→ 确认
4. 系统自动解绑旧微信并**自动重试绑定** → 成功即回到首页

**解绑规则**：

| 规则 | 说明 |
|---|---|
| 解绑只解除**微信与工号的绑定关系** | **不影响**该账号的任何历史课时数据、统计与审计记录 |
| 旧登录态立即失效 | 解绑后，该工号**此前签发的所有 token 立即失效**（旧微信手里未过期的也失效）|
| 频率限制 | 同一工号 24 小时内最多自助解绑 **2 次**；同一 IP 1 小时内最多 **5 次**（**失败尝试同样计数**）|
| 留痕 | 每次解绑都写入操作日志，管理后台可查（含工号、姓名、IP、设备、时间）|
| 超限处理 | 提示"该工号今日自助解绑次数已达上限，请联系教务处" |
| 防探测 | "工号不存在"与"姓名不符"返回**同样的提示**，无法用来枚举工号 |

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 真机一直停在「绑定中…」 | 微信真机要求 **HTTPS + 已备案域名**。测试期请在手机端小程序右上角「…」菜单开启「**开发调试**」后重进；或在开发者工具中用「真机调试」。正式使用需配置已备案 HTTPS 域名 |
| 提示「请求域名未在微信公众平台配置」 | 同上；绑定页顶部会显示该提示，可点「重新检测连接」 |
| 提示「已被其他微信绑定」 | 一个工号/学号只能绑一个微信。开发模式下退出登录后可重新绑定；生产环境需教务处解绑 |
| 提示「不在白名单内 / 对应姓名为 X / 的角色为 Y」 | 姓名、工号学号或身份与白名单不一致，请按下表逐字核对 |
| 点「出示二维码」提示已发起过 | 同一班级 + 日期 + 节次 + 授课人只能有一条有效课时；系统会自动复用该会话并刷新二维码 |
| 动态码过期（41001） | 二维码 60 秒有效，请班干部点「刷新二维码」后再扫 |
