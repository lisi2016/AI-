# 设计系统 · 课堂课时确认与学时统计小程序

- 生成日期：2026-09-27
- 阶段：设计（UI 方案已确认，等待原型确认）

## 1. 目的与审美方向

面向**中老年教师**与**学生班干部**在课间、走廊、教室等场景下使用，目标是"扫一眼就懂、三步内做完"。

审美方向采用用户选定的 **A 方案：微信原生稳妥方向**——界面与微信自带页面保持一致，教师不需要学习任何新交互；不追求品牌辨识度，把实现风险压到最低。

取舍：接受"视觉平淡、学时数字不醒目"的缺点，换取最快上线、最小包体、最低兼容风险。若试运行后教师反馈"看不清数字"，再按 C 方案的大字号方案做局部改造（那时属于已上线项目的局部更新，不需要重走三套方案门禁）。

## 2. 方案来源与版本

| 来源 | 作用 | 版本/快照 | 许可证 |
|---|---|---|---|
| 微信官方小程序设计指南 | 导航、触控、安全区、反馈规则 | 2026-09-27 访问 | 官方文档 |
| WeUI 设计规范 | 颜色、字号、间距、列表与表单样式 | WeUI 2.x 设计 token | MIT |
| 原生小程序组件 | 按钮、输入、选择器、canvas、tabBar | 微信基础库 | 平台能力 |

本项目**不引入第三方组件库 npm 包**，只采用 WeUI 的设计 token（颜色、字号、间距、圆角）与布局规范，组件实现全部使用原生组件。理由：A 方案的核心价值是低风险与低包体，引入 TDesign 会否掉这一取舍。

## 5. 主组件库

**WeUI 设计规范（样式 token 与布局） + 原生组件实现**。一个项目只选一个主组件库，本项目不混用 TDesign / Vant，也不引入 npm 组件库包。

## 6. WXML/WXSS 可落地检查

| 原型元素 | 小程序实现 | 组件来源 | 风险或降级 |
|---|---|---|---|
| 主按钮（扫描确认码、提交、签名确认） | `<button>` + `hover-class` | 原生 | 需处理加载中禁用与重复点击防抖 |
| 页面卡片 / 列表行 | `<view>` + WXSS 边框与 1px 分割线 | 原生 | A 方案不使用阴影，无安卓阴影差异风险 |
| 底部导航 | **原生 `tabBar`**（`app.json`，3 项） | 原生 | 图标必须为项目内本地 PNG，准备 `iconPath` 与 `selectedIconPath` |
| 顶部导航 | 原生导航栏 | 微信平台能力 | 天然避开胶囊，无需自定义 |
| 表单输入（缺勤人数、姓名、摘要） | `<input>` / `<textarea>` | 原生 | 缺勤姓名需按顿号/逗号自动切分（决策 6） |
| 单选（课堂纪律 好/一般/差） | `<radio-group>` 或 `<picker>` | 原生 | 默认选中"好" |
| 日期时间（实际上课时间） | `<picker mode="date">` + `<picker mode="time">` | 原生 | 默认值取当前日期 |
| 动态二维码 | **由服务端生成二维码图片 URL**，`<image>` 展示 | 后端 + 原生 image | 降级：若后端暂未提供，前端用 `weapp-qrcode` canvas 生成（需评估包体，约 10KB） |
| 手写签名 | `<canvas>` + `bindtouchstart/move/end`，`wx.canvasToTempFilePath` 导出 | 原生 canvas | 需按 `pixelRatio` 处理清晰度；导出图片体积需压缩后上传 |
| 定位采集 | `wx.getLocation` + `app.json` 声明 `requiredPrivateInfos` | 微信平台能力 | 必须先在公众平台隐私保护指引申报"位置信息"；拒绝授权时走降级留痕，不阻断提交 |
| 状态标签 | `<view>` + WXSS | 原生 | 8 种状态各一套配色 |
| 加载 / Toast | `wx.showLoading` / `wx.showToast` | 微信平台能力 | — |
| 空状态 / 错误重试 | `<view>` 自定义块 + 重试按钮 | 原生 | — |
| 弹窗（定位授权说明、提交确认） | `<view>` 自定义蒙层 或 `wx.showModal` | 原生 | 授权说明优先用自定义半屏弹窗，`wx.showModal` 作兜底 |

明确**不使用**的效果（避免无法落地）：渐变背景、`backdrop-filter`、复杂 `clip-path`、SVG 动画、WebGL、hover 专属交互、远程字体与远程 CDN 图标。

## 7. tabBar 方案

采用**原生 tabBar**，3 项，身份差异在页面内按角色渲染（`wx:if`），不使用自定义 tabBar：

| 项 | 文案 | 教师端内容 | 班干部端内容 | 管理员端内容 |
|---|---|---|---|---|
| 1 | 首页 | 工作台：扫码发起 + 今日课程 + 本周学时 | 我的确认码（60 秒刷新） | 统计看板 |
| 2 | 记录 | 课时记录列表 + 学时统计入口 | 历史确认记录 | 明细查询 |
| 3 | 我的 | 身份、绑定、退出 | 身份、绑定、退出 | 身份、退出 |

需要的本地 PNG 图标（每项 2 个状态，共 6 个文件，建议 81×81，透明底，单色）：

```text
assets/icons/home.png        assets/icons/home_on.png
assets/icons/record.png      assets/icons/record_on.png
assets/icons/mine.png        assets/icons/mine_on.png
```

原生 tabBar 不使用网络图片、SVG、iconfont 或 emoji。图标来源待定：优先使用有明确许可证的开源图标集（如 WeUI 自带资源或自绘 PNG），交付前记录来源与许可证。

## 8. 状态设计

每个数据页面至少包含：正常、加载中、空数据、错误（含重试）。涉及权限的页面额外包含：拒绝授权、重新授权入口。

| 状态 | 页面 |
|---|---|
| 加载中 | 首页、记录列表 |
| 空数据 | 今日无课、无待确认记录、无历史记录 |
| 错误重试 | 列表请求失败、提交失败 |
| 拒绝定位授权 | 发起确认页（降级：不采定位，记录"未授权"并继续提交） |
| 二维码过期 | 班干部出示码页（60 秒后自动刷新，提供手动刷新） |
| 拒绝确认 | 班干部核对页（原因必填，填后方可提交） |

## 9. API / 存储字段到 UI 字段映射

| UI 显示 | 数据字段 | 空值/异常降级 |
|---|---|---|
| 课程名 + 节次 + 时间 | `course_name`、`section`、`start_time`/`end_time` | 缺失显示"待补充" |
| 班级 | `class_name` | 缺失显示"—" |
| 地点 | `location_name` | 缺失显示"地点未填" |
| 学时 | `hours`（默认 1.0 系数） | 缺失显示 0 |
| 状态标签 | `status`（8 态） | 未知状态按"待确认"处理并记日志 |
| 缺勤 | `absent_count`、`absent_names[]` | 未填显示"未记录" |
| 课堂纪律 | `discipline`（默认 `good`） | 未选按"好" |
| 签名图 | `signature_image` | 加载失败显示"签名加载失败，重试" |
| 证据：时间/地点/设备/动态码 | `confirmed_at`、`geo`、`device_info`、`dynamic_code` | 定位未授权显示"未授权" |
