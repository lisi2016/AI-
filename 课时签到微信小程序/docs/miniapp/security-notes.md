# 凭据与数据安全须知

## 一、AppSecret（小程序密钥）处理约定

- **AppSecret 不进入本项目任何文件**，包括源码、配置、文档、注释、提交历史。
- 本文件只记录"是否已处理"，不记录密钥本身。
- AppSecret 只在**服务端**使用（`code2session` 换取 openid、获取 access_token 等）。
  小程序前端**任何时候都不需要、也不应该**持有它。
- 首版走 mock 数据层，暂不需要 AppSecret。等接入真实后端时，由服务端环境变量注入，
  不写进 `project.config.json`、不上传代码仓库。

## 三、其他敏感信息边界

以下内容同样不得写入项目文件，也不应发送给智能体：

- 登录/审核测试账号的密码、验证码
- AppSecret、SecretKey、API Key、支付密钥
- 身份证号、证件图片、手机号
- 学生真实姓名与学号的完整名单（正式数据由后台导入，演示数据用假名）

## 四、学生数据

- 首版 `utils/mock.js` 中的姓名、班级、工号学号**全部为演示数据**。
- 真实课表与学生名单一律通过后台导入，不硬编码进小程序包体。
- 签名图片落盘在小程序用户目录（`wx.env.USER_DATA_PATH`），正式版应上传服务器并加密存储，
  留存期限按学校教学管理数据要求执行（需求要求 5 年）。
